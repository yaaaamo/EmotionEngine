User: "What is JSON Lines format and how is it different from a JSON array?"

AI Response:
"JSON Lines (also called JSONL or newline-delimited JSON) is a format where each line is a separate, valid JSON object:

{'name': 'Alice'}
{'name': 'Bob'}

Unlike a JSON array, you don't need commas between items or wrapping brackets. This makes it easy to stream and process line by line without loading everything into memory."

What I used/changed: I understood the input format requirement - one JSON object per line, not a JSON array. Each line is processed independently.

User: "How do I handle errors gracefully in the dialogue loop without crashing?"

AI Response:
"Wrap your JSON parsing and processing in try-except blocks:

try:
    data = json.loads(line)
    # process
except json.JSONDecodeError:
    # return error response
except Exception:
    # handle other errors

This way, if one line fails, you can return an error response and continue processing the next lines."

What I used/changed: I added try-except blocks in process_line() to handle JSONDecodeError and general exceptions, returning ask_clarification action on errors.
